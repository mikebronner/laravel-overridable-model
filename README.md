# laravel-overridable-model
Provide a uniform method of allowing models to be overridden in Laravel.

## Requirements

| Version | PHP | Laravel |
|---------|-----|---------|
| 1.x | 8.2, 8.3, 8.4, 8.5 | 10.x, 11.x, 12.x |

## Installation
```sh
composer require genealabs/laravel-overridable-model
```
